# Feather Launcher

A Minecraft launcher inspired by the old Feather client aesthetic.

## Features
- Dark modern launcher UI
- Version dropdown
- Java memory settings
- Game directory input
- Launch logic for local Minecraft jar

## Run

```bash
npm install
npm start
```

## Notes
This is a starter project meant to mimic the look and feel of old Feather-style launchers. It does not include Mojang authentication or a full modpack manager.
